# CCNA Learning & Packet Tracer Labs

This repository documents my CCNA learning journey.

The goal is to learn the networking concepts required for the Cisco CCNA 200-301 certification and practice them with Cisco Packet Tracer.

---

## Learning Method

For every topic I:

1. Learn the theory
2. Answer practice questions
3. Build Packet Tracer labs
4. Inspect and troubleshoot the network
5. Document the lab step by step

## Lab 01 - First LAN

The first lab contains:

```text
PC0 -------- Switch0 -------- PC1
```

Topics practiced:

- static IPv4 configuration
- Ethernet
- MAC addresses
- ARP
- ICMP
- ping
- switch MAC address tables
- broadcast traffic
- Packet Tracer Simulation Mode
- Gratuitous ARP

Lab instructions:

```text
01-network-fundamentals/labs/01-first-lan.md
```

Completed Packet Tracer file:

```text

```
